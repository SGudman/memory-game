# Memory Game

Игра на поиск пар животных: 16 карточек, 8 пар. Найдите все пары за наименьшее число ходов.

- «Новая игра» перемешивает карточки и сбрасывает счётчики.
- «Таблица лидеров» показывает 10 лучших результатов с числом ходов и датой.
- Результаты сохраняются в `localStorage` этого браузера. Звук и подключение к внешним сервисам не нужны.

## Локальный запуск

Нужны современный браузер и Python 3. Установка зависимостей и сборка не требуются.

В папке репозитория выполните:

```bash
python3 -m http.server 8174 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8174/>. Для остановки сервера нажмите `Ctrl+C` в его терминале. Если порт занят, остановите ранее запущенный сервер или выберите другой свободный порт и откройте соответствующий адрес.
