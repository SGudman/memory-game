# Twemoji animal artwork

The eight animal images in `animals/` are original SVG graphics from the [`jdecked/twemoji`](https://github.com/jdecked/twemoji) project. They were downloaded without modifying the artwork. The upstream project identifies its contributors in the [contributors list](https://github.com/jdecked/twemoji/graphs/contributors) and asks projects using Twemoji graphics to provide a mention; this file is that attribution.

## Pinned source

- **Release:** Twemoji `v17.0.3` (Emoji 17.0)
- **Git commit:** [`b6b55fef1e8636b540a6d016a4729ca8cdf2e60b`](https://github.com/jdecked/twemoji/commit/b6b55fef1e8636b540a6d016a4729ca8cdf2e60b)
- **Upstream project:** [jdecked/twemoji](https://github.com/jdecked/twemoji)
- **Artwork license:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- **License text:** [`LICENSE-GRAPHICS.txt`](LICENSE-GRAPHICS.txt), included from the pinned upstream commit with trailing whitespace normalized.
